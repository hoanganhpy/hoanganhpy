### 🛍️ ShopNAV — fashion e-commerce · [repo](https://github.com/hoanganhpy/ShopNAV)

<a href="https://github.com/hoanganhpy/ShopNAV"><img src="https://raw.githubusercontent.com/hoanganhpy/ShopNAV/master/docs/screenshots/home.jpg" alt="ShopNAV storefront" width="100%"></a>

A full online clothing store that runs with `npm install && npm start`.

- Catalogue with filters, search and sorting · per-size stock · session cart · transactional checkout · order tracking and cancellation
- Admin dashboard with revenue charts, order workflow, product editor with image upload and size stock
- bcrypt, CSRF tokens, strict Content-Security-Policy, rate-limited login, server-side pricing
- Integration tests with `node:test` + Supertest, CI on GitHub Actions

`Node.js` `Express` `SQLite` `EJS` `Chart.js`

### 💍 WebDoji — jewelry store · [repo](https://github.com/hoanganhpy/WebDoji_Nodejs)

<a href="https://github.com/hoanganhpy/WebDoji_Nodejs"><img src="https://raw.githubusercontent.com/hoanganhpy/WebDoji_Nodejs/main/docs/screenshots/home.jpg" alt="WebDoji storefront" width="100%"></a>

Storefront and back-office for a jewelry shop, redesigned and hardened from a university project.

- Custom design system, responsive storefront, admin with KPI dashboard and sales statistics
- Found and fixed 12+ real bugs: forged logins, other users' orders exposed, shared carts, client-side prices, a checkout that could never submit
- MySQL connection pool, security headers, rate limiting, documented schema and seed data

`Node.js` `Express` `MySQL` `EJS` `Chart.js`
